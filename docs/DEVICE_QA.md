# בדיקות גרסה 1.2.0

תאריך: 6 באוקטובר 2026. APK חתום במפתח ההפצה המקורי.

## שחקנים וטבלת שיאים ב־1.2.0

- בדיקות אחסון: העברת ההתקדמות לשחקן הראשון, הפרדה בין שחקנים, שמות כפולים ולא תקינים, החלפת שיא רק בתוצאה טובה יותר, דירוג, טעינה מחדש וכשל שמירה.
- בדפדפן: יצירת שני שחקנים, פתרון שלב בממשק לכל אחד, דירוג כללי ולשלב, החלפת שחקן, משחק כאורח, שמירה אחרי רענון, עבודה ללא רשת וממשק ברוחב 320 פיקסלים.
- בדיקות הפיזיקה של 90 השלבים ובדיקת ממשק המשחק הקיימת עברו. בניית APK שחרור ובדיקת lint עברו.
- APK חתום 1.2.0 הותקן כעדכון בנייד SM-A736B. נצפתה שמירת 24 השלבים הקיימים והעברתם לשחקן הראשון. שחקן נוסף שנוצר בנייד קיבל התקדמות נפרדת.

```sh
npm test
node tests/players-browser.mjs
node tests/android-players.mjs --serial DEVICE_ID
```

בדיקת השחקנים בטלפון דורשת שחקן בשם שכבר השלים שלב, ומכשיר שלא משתמשים בו בזמן הבדיקה. היא פותחת את הטבלה ומפעילה מחדש את האפליקציה בלי למחוק נתונים.

## בדיקות קמפיין קודמות ב־1.1.0

## היקף הבדיקה

- כל 90 השלבים נפתרים במנוע הפיזיקה דרך פעולות עריכה חוקיות; כל הסידורים ההתחלתיים נכשלים.
- בדפדפן: פתרון כל שלב בעכבר ובמגע, בדיקת החלקים הקבועים ושמירת הסידור בניסיון מחדש — 180 מסלולי בדיקה.
- בדיקות ממשק נוספות: תנועה מוגבלת לציר, סיבוב סביב עוגן, כפתורי מגע, בחירת עוצמה, מפה, עזרה, שמירת התקדמות וטעינה ללא רשת.
- בטלפון Samsung Galaxy A73 ‏(SM-A736B), Android 16, WebView 154.0.8037.57: פתרון באמצעות מחוות מגע של השלבים 1, 4, 5, 10, 15, 20, 25, 30, 33, 45, 61, 67, 71, 75, 80, 88 ו־90. בכל אחד נבדקו ניצחון וניסיון מחדש.
- בטלפון נבדקו גם כישלון ברור, עזרה, כפתור החזרה של Android, השתקה, חזרה מרקע ושמירת התקדמות אחרי סגירת התהליך ופתיחה מחדש.

הבדיקה הפיזית מכסה 17 שלבים ומנגנונים מייצגים. כל 90 השלבים נבדקים במגע בדפדפן; אין טענה שכל 90 שוחקו בטלפון.

## ביצועים בטלפון

הקטנת רזולוציית הציור לגודל התצוגה בפועל שיפרה את אותו שלב: חציון זמן פריים ירד מ־53ms ל־19–21ms; שיעור הפריימים שאיחרו ירד מכ־24% ל־0.34–0.70% בשתי חזרות.

בקמפיין החדש, במדידות `adb shell dumpsys gfxinfo` בזמן הרצה:

| שלב | פריימים | חציון | פריימים שאיחרו |
| --- | ---: | ---: | ---: |
| 30 | 227 | 10ms | 0.88% |
| 90 | 557 | 20ms | 0.36% |

אלו מדידות במכשיר אחד, ללא הבטחה לקצב זהה בכל מכשיר. הבדיקות מוכיחות תקינות ויכולת פתרון; כיול הקושי וההנאה דורש גם משוב משחקנים.

## הרצה חוזרת

```sh
npm test
node tests/audit.mjs
node tests/browser.mjs
node tests/pivot-touch.mjs
node tests/touch-button.mjs
node tests/android-device.mjs --serial DEVICE_ID
```

לבדיקה הפיזית נדרש APK מותקן, טלפון פתוח וחיבור ADB מורשה. אפשר להגדיר `CHAIN_ADB` לנתיב כלי ADB ולהגביל שלבים באמצעות `--levels 30,71,90`. צילומי המסך ודוחות הבדיקה נכתבים ל־`output/` ואינם מועלים למאגר. בניית Android ובדיקת lint עברו; קיימות אזהרות לא חוסמות לגבי התאימות והספריות.
