# מבנה 90 השלבים

הקמפיין כולל 30 שלבי יסוד שנבחרו מתוך 60 השלבים המקוריים, ואחריהם 60 שרשראות חדשות. השלב המקורי 60 נמצא כעת במקום 30; ההשלמה שלו ממשיכה לשלב 31.

| שלבים | הרעיון המרכזי |
| --- | --- |
| 1–5 | מסילות: אזור הצבה, ציר תנועה ועוגן סיבוב |
| 6–10 | להפעיל דומינו מהכיוון והגובה הנכונים |
| 11–15 | קשתות וקפיצים |
| 16–20 | פגושים: לתפוס ולשנות כיוון |
| 21–25 | כניסה ויציאה ששומרות על התנופה |
| 26–30 | מתגים, שערים ושילוב עם זמן מוגבל |
| 31–40 | לחבר קשת לקשת, למסילה או לפגוש |
| 41–50 | שני זוגות מעברים ושילובים משני צדי הלוח |
| 51–60 | לתכנן נחיתה אחרי כמה שינויי כיוון |
| 61–70 | שני מתגים שצריכים להיות פעילים יחד |
| 71–80 | לבחור עוצמת קפיץ ולכוון לפי המהירות שנוצרת |
| 81–90 | לשלב כוח, מעברים, מנעולים ודומינו בשרשרת אחת |

כל שלב חדש מוגדר לפי סדר אחר של מפגשים פיזיים. החלקים כבר נמצאים על הלוח; השחקן משנה רק את החלקים המורשים. חלקים מסוימים קבועים, אחרים מסתובבים סביב עוגן או נעים לאורך ציר. בחירת עוצמה מוצגת רק בקפיץ שבו שינוי העוצמה משפיע על היכולת להשלים את המסלול.

המעברים מסומנים בזוגות: כניסה ויציאה עם אותו מספר מחוברות. שני מתגים מחוברים לאותו שער, שנפתח רק כשהתנאים של שניהם מתקיימים. לכל מתג מתוזמן יש זמן משלו; הזמן נספר מרגע הפגיעה בו.

מחיצות ומלכודות נשמרות רק אם הן מפריעות לטעות אפשרית שנבדקה, ולא כקישוט. הפתרונות אינם דורשים להזיז חלק קבוע או לעבור דרך מחיצה. ניסיון מחדש שומר את כל הסידור ואת עוצמות הקפיצים.


המספרים מתייחסים לגרסה המקורית. ההתקדמות עוברת לפי זהות השלב. שלבים שנשמרו והושלמו נשארים מסומנים לאחר העדכון; השלבים שהוסרו אינם נספרים בקמפיין החדש.

## עריכה ובדיקה

30 שלבי היסוד נמצאים ב־`scripts/foundation-levels.json`. המסלולים של 60 השלבים החדשים מוגדרים ב־`scripts/expand-campaign.mjs`. הסקריפט מחשב את המיקומים מראש באמצעות אותו מנוע פיזיקה של המשחק ומפיק הגדרות יציבות ופתרונות בדיקה.

```sh
node scripts/expand-campaign.mjs
npm test
node tests/audit.mjs
```

המשחק עצמו אינו מחפש פתרון או משנה שלבים בזמן המשחק. בדיקת הסימולציה אינה קובעת אם החידה מהנה; המטרה שלה היא למנוע שלבים שבורים, חלקים חסרי משמעות ופתרונות שאינם אפשריים דרך הממשק.
