# CHAIN / REACTION

משחק פיזיקה לשחקן יחיד, שתוכנן למסך מגע: מסדרים כמה חלקים, משחררים כדור וצופים בתגובת שרשרת. 90 חידות ב־12 פרקים, עם מסילות, דומינו, קפיצים, פגושי גומי, מעברים ומתגים.

הקמפיין מתחיל ב־30 שלבים שנבחרו מתוך 60 השלבים המקוריים. השלב הישן 60 נמצא כעת במקום 30. אחריו מגיעות 60 שרשראות חדשות: כמה קפיצים, שני זוגות מעברים, שני מנעולים ובחירת עוצמה. [מבנה השלבים וההתקדמות](docs/CAMPAIGN.md).

## התקנה באנדרואיד

1. הורידו את `chain-reaction-1.2.0.apk` מדף הגרסה.
2. פתחו את הקובץ במכשיר ואפשרו התקנה מהדפדפן או ממנהל הקבצים, אם Android מבקש זאת.
3. התקינו והפעילו **CHAIN / REACTION**.

נדרש Android 8 ומעלה ו־Android System WebView מעודכן. המשחק, הגופנים והשלבים נמצאים ב־APK. האפליקציה פועלת ללא חיבור, בלי חשבון ובלי הרשאת אינטרנט. ההתקדמות נשמרת במכשיר. עדכון עם אותו מזהה ואותה חתימה שומר את הנתונים; הסרת האפליקציה מוחקת אותם.

## איך משחקים

- לחצו על **בחירת שחקן** והוסיפו שם, בלי Google ובלי סיסמה. אפשר להחליף בין כמה שחקנים במכשיר, עם התקדמות נפרדת לכל אחד. השחקן הראשון מקבל את ההתקדמות הקיימת.
- **טבלת שיאים** מציגה דירוג כללי ושיאים לכל שלב. בשלב בודד פחות ניסיונות עדיפים, ובשוויון זמן הכדור הקצר יותר מנצח. בדירוג הכללי יותר שלבים עדיפים; בשוויון יותר שיאים מדודים, פחות ניסיונות ואז זמן הכדור.
- שמות, התקדמות ושיאים נשמרים במכשיר בלבד ועובדים ללא רשת. משחק כאורח שומר התקדמות אבל לא נכנס לטבלת השיאים.

- גררו חלק נייד בתוך אזור ההצבה. קו מנחה מגביל תנועה לציר אחד.
- במסילה מעוגנת, גררו את הקצה לסיבוב סביב העוגן העגול. ידית עגולה מאפשרת סיבוב בחלקים נוספים.
- מנעול מסמן חלק קבוע. מתחת ללוח מופיעה הפעולה המותרת לחלק שבחרתם.
- השלימו את התחנות לפי הסדר ואז הגיעו ליעד. בשלב דומינו, החלק האחרון בשורה חייב ללחוץ על היעד.
- מחיצות עוצרות את הכדור; מלכודות מסיימות ניסיון. חלק מהמתגים פותחים שער לזמן מוגבל.
- כניסה ויציאה עם אותו מספר שייכות לאותו זוג. בשלב עם שני מתגים, שניהם חייבים להיות פעילים כדי לפתוח את השער.
- בקפיץ מתכוונן, בחרו את הקפיץ ולחצו על כפתור העוצמה כדי להחליף בין שלוש דרגות כוח.
- ניסיון מחדש שומר את הסידור. איפוס סידור השלב מחזיר את המצב ההתחלתי.

הפרקים מציגים בהדרגה עוגנים, תנועה בציר, העברת תנופה, קפיצות, מסלולי חזרה, מעברים וסדר ותזמון. רמזים ומפת כל 90 השלבים זמינים בכל רגע. העדכון מעביר את ההתקדמות של השלבים שנשמרו אל המספור החדש.

## הפעלה בדפדפן

נדרש Node.js 20 ומעלה. לשרת ולמשחק אין תלויות npm.

```sh
npm start
```

פתחו [localhost:5173](http://localhost:5173). מקלדת: חצים להזזה, A/D לסיבוב, Tab לבחירת חלק כשהלוח ממוקד, רווח להפעלה, R לניסיון מחדש ו־F למסך מלא. גירסת הדפדפן תומכת בשמירה מקומית ובמטמון ללא חיבור לאחר טעינה ראשונה ב־HTTPS או ב־localhost.

## בדיקות

```sh
npm test
```

הבדיקה מריצה פתרון חוקי לכל 90 השלבים דרך מנגנון העריכה של השחקן. היא בודקת אילוצים, סדר, מחיצות, מלכודות, שערים, בחירת עוצמה, מניעת דילוג ליעד, איפוס ניסיון והעברת התקדמות.

בדיקות הממשק דורשות Playwright ו־Chromium, ושרת פעיל:

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.mjs
node tests/pivot-touch.mjs
node tests/touch-button.mjs
node tests/audit.mjs
```

`audit.mjs` משלים את כל 90 השלבים בעכבר ואת כל 90 השלבים באירועי מגע, ובודק ניסיון מחדש בכל שלב. הבדיקות עברו בכרומיום. בדיקות המגע הנוספות מכסות רוחב 390 ו־320. Android נבדק באמצעות קומפילציית release, Android Lint, אימות חתימת APK ובדיקות במכשיר Samsung Galaxy A73 עם Android 16. [דוח בדיקת המכשיר](docs/DEVICE_QA.md).

בדיקה של ה־APK המותקן על מכשיר מורשה ומחובר ב־ADB:

```sh
node tests/android-device.mjs --serial DEVICE_ID
```

הבדיקה מפעילה מחוות מגע אמיתיות ב־17 שלבים מייצגים, כולל שלב 90, ומאמתת השלמה, ניסיון מחדש, הוראות, חזרה של Android ושמירת התקדמות. השאירו את הטלפון פתוח בלי לגעת במסך במהלך הבדיקה. קובצי הבדיקה נשמרים ב־`output/android-device/` ואינם חלק מהמאגר.

GitHub Actions בונה ובודק את הפרויקט. APK ההורדה נחתם במפתח שחרור פרטי שאינו נמצא במאגר. ראו [הוראות בנייה](docs/ANDROID.md).
